Confini del prototipo

HTML, CSS e JavaScript locali, senza build né dipendenze remote. Non è un’applicazione React/Mantine: ne rappresenta gerarchie e componenti per l’implementazione. Le modifiche usano localStorage se disponibile, altrimenti restano in memoria. Nessun servizio remoto, autenticazione o automazione AI.

Il layout Notion-like segue la richiesta più recente. Le proprietà di Space restano fisse; le proprietà locali di un’entità sono l’eccezione controllata di ADR-0024. Nessun costruttore di viste, colonne o gerarchie. I corpi dei documenti e le date relative non specificati sono contenuti dimostrativi. Le varianti opzionali del brief non sono incluse.
